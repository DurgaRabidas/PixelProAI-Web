# PixelPro AI

PixelPro AI is a browser-based image editing application.

## Current Features
- Upload image
- Preview image
- Rotate
- Flip
- Brightness
- Contrast

## Planned Features
- Crop
- Filters
- Download image
- AI Background Remover
- AI Image Enhancement

## Technologies
- HTML
- CSS
- JavaScript
